# Neubau

neubau is a modern, minimal, responsive portfolio/business theme by Elmastudio. neubau offers a with a custom front page, a fullscreen slider option, a team, services, portfolio and testimonials page template and many more features.

By [Elmastudio](https://www.elmastudio.de/en/).

- **Version:** 1.0.10
- **Theme page:** https://www.elmastudio.de/en/themes/neubau/
- **Documentation:** [English](https://www.elmastudio.de/en/docs/neubau/) / [German](https://www.elmastudio.de/doks/neubau/)

## Installation

Download this repository as a ZIP and upload it in **Appearance → Themes → Add New → Upload Theme**, or clone it into your WordPress installation:

```
cd wp-content/themes
git clone https://github.com/elmastudio/neubau.git
```

## Status

This theme is no longer actively developed. It is published here as-is, for anyone who still runs it or wants to build on it.
